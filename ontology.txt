---
Dataset:
  definition: >
    A collection of scientific data describing one or more quantities
    over a spatial or spatial-temporal domain.

Field:
  definition: >
    A quantity contained in a dataset, such as pressure, temperature,
    density, or velocity.

Grid:
  definition: >
    The spatial structure on which fields are defined.

Scalar:
  definition: >
    A field containing one scalar value per associated grid element.

Vector:
  definition: >
    A field containing multiple components representing a vector quantity.

Tensor:
  definition: >
    A field containing multiple components representing a tensor quantity.

Point:
  definition: >
    A location defined by the grid.

Cell:
  definition: >
    A spatial element defined by a collection of grid points.

UniformGrid:
  definition: >
    A regular grid with uniform spacing.

RectilinearGrid:
  definition: >
    A structured grid with independently varying coordinates along each axis.

StructuredGrid:
  definition: >
    A grid with regular topology and arbitrary coordinates.

UnstructuredGrid:
  definition: >
    A grid with arbitrary topology and geometry.

Static:
  definition: >
    A dataset containing a single state in time.

TimeVarying:
  definition: >
    A dataset containing multiple states in time.
---

Dataset <has> [1] Grid
Dataset <has> [1..*] Field

Dataset <temporal_type> [1] {Static, TimeVarying}

Grid <grid_type> [1] {
    UniformGrid,
    RectilinearGrid,
    StructuredGrid,
    UnstructuredGrid
}

Grid <spatial_dimensions> [1] {1, 2, 3}

Grid <size_x> [0..1] integer
Grid <size_y> [0..1] integer
Grid <size_z> [0..1] integer

Field <data_type> [1] {Scalar, Vector, Tensor}
Field <association> [1] {Point, Cell}

Field <name> [1] string
Field <components> [1] integer
Field <units> [0..1] string

Field <minimum> [0..1] number
Field <maximum> [0..1] number
