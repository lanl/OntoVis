## Workflow

### Getting Started
1. Read [README.md](README.md) for project overview
2. Check [QUICKSTART_VOLUME.md](QUICKSTART_VOLUME.md) for quick commands
3. Set up your `.config` file (see README)

### Analyzing Data
1. Read [VOLUME_ANALYSIS.md](VOLUME_ANALYSIS.md)
2. Check [FORMATS.md](FORMATS.md) for your file format
3. Run analysis on your dataset

### Visualizing Data
1. Read [VOLUME_RENDERING.md](VOLUME_RENDERING.md)
2. Use natural language prompts
3. Iterate with different thresholds

### Interactive Mode
1. Read [INTERACTIVE_CLI.md](INTERACTIVE_CLI.md)
2. Launch: `python examples/interactive_cli.py`
3. Chat naturally with the AI
